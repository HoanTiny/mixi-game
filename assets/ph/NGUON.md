# Mô hình và vật liệu Poly Haven (CC0)

Tải từ [Poly Haven](https://polyhaven.com) bằng API công khai, giấy phép **CC0** (dùng tự do, không cần ghi công; vẫn ghi
lại cho rõ nguồn). Ảnh vật liệu thu nhỏ về 512 px cho bản web nhẹ. Dùng ở các chỗ làm 3D (`scripts/work/`).

- Mô hình (`models/`): cardboard_box_01, plastic_crate_01, plastic_crate_03, barrel_03, plastic_monobloc_chair_01,
  pot_enamel_01, wooden_bowl_02, bench_vice_01, metal_tool_chest, metal_office_desk, power_box_01, wooden_ladder,
  wooden_bookshelf_worn, boombox, hanging_industrial_lamp, portable_generator, metal_stool_01, potted_plant_04,
  industrial_storage_cart.
- Vật liệu (`textures/`): concrete_floor_02, concrete_floor_worn_001, worn_tile_floor, painted_plaster_wall,
  plastered_wall_04, brown_planks_05, corrugated_iron, rusty_metal_sheet.
